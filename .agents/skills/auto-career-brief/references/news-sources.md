## 후보 탐색 원칙

- industry 또는 both 실행에서는 5곳의 관련 기사 목록이나 해당 도메인 검색을 확인한다. 찾은 기사 수를 채우기 위해 모든 기사를 읽을 필요는 없다. 사용자가 특정 출처만 요청하면 그 범위를 따른다. job 전용 실행에서는 공식 채용·직무 자료를 우선하고 5곳을 기계적으로 검색하지 않는다.
- 검색·열람에서 사용할 도메인은 표에 있는 실제 주소를 사용한다. 목록이 읽히지 않으면 도메인 검색으로 공개 기사를 찾을 수 있으나 권한·정책 차단을 우회하지 않는다. 검색 요약만 나온 경우 본문 확인 성공으로 기록하지 않는다.
- 매체 수와 기업의 다양성은 별개다. 현대·기아·제네시스 기사만 계속 모으지 말고 국내 다른 완성차, 해외 완성차·중국 브랜드, 모빌리티 서비스 사례를 함께 찾아본다.
- 최종 선정 전 동일 기업집단과 동일 매체에 편중됐는지 확인한다. 적합한 자료가 있으면 서로 다른 기업집단과 발행 매체를 우선 포함한다. 비율이나 개수를 억지로 맞추지 말고 편중이 남는 이유를 알린다.
- 자극적 제목, 차량 외형만 소개하는 기사보다 고객 문제·가격/사양 결정·사업 운영·판매/서비스 개선에 연결할 수 있는 자료를 우선한다. 시승자의 주관적 평가를 전체 고객 의견이나 만족도 조사로 일반화하지 않는다.

## 취업 준비용 중요도와 뉴스 태그

- 국내 시장과 주요 완성차의 변화를 우선한다. 판매량이 높은 브랜드·모델인지 판단할 때는 최근 공식 통계의 기간·지역·판매/등록 기준을 확인한다. 유명하다는 이유로 판매 상위라고 단정하지 않는다.
- 판매량이 적어도 새로운 차급·기술·가격 구조 등 시장에 큰 영향을 줄 가능성이 구체적으로 드러나면 포함한다. 사이버트럭은 예시이며 특정 모델을 무조건 수집하는 규칙이 아니다.
- 사업기획 또는 상품기획의 실제 판단으로 연결할 수 있어야 한다. 어떤 고객 선택·가격/사양·운영 결정을 공부할 수 있는지 설명하지 못하면 후순위로 둔다.
- 소규모 에디션, 개별 매장 개점, 국내 영향이 불분명한 해외 실증, 변화가 없는 시험 경과는 기본 후순위다. 과거 사용자 X 평가 기사와 같은 약점을 반복하지 않는다. 새로 검색 요청 시 이전 후보 재정렬로 대신하지 않는다.
- 사용자 O 평가와 X 평가를 AI의 대표 선정 여부와 구분한다. 이전 발행 기사라는 이유로 O 평가를 뒤집지 않는다. 게시할 DB에는 최종 적합 기사만 추가하며 후보·보류·제외 이유는 로컬 output에 남긴다. 기존 기사 삭제는 사용자 요청 범위에서만 수행한다.
- 뉴스 태그는 `신차 / 판매·시장 / 가격·혜택 / 기술·사업 / 고객·서비스 / 마케팅 / 인프라 / 정책·안전 / 사회공헌` 중 핵심1~2개를 부여한다. 신차는 풀체인지·부분변경·신규 모델 등을 포함한다. 태그는 빠른 내용 구분용이며 태그별 수량을 채우거나 선정 기준 대신 쓰지 않는다.

## 원문과 재전송

### 회차 간 중복과 해외 기사 판단

- Scout가 새 후보를 찾고 Curator가 기존 발행 기록(로컬 전송 기록·Notion 발행 목록 등)과 사건 단위로 비교한다. URL·매체·제목이 달라도 같은 기업/모델의 같은 발표면 중복이다. 같은 사전예약 소식의 재보도는 다음 회차에서 제외한다. 사용자 O 평가는 보존하되 재게재 승인으로 해석하지 않는다.
- 확정 가격·국내 출시·실제 판매 결과·중요 조건 변경처럼 새로운 사실이 있으면 이전 보도와 달라진 점과 원문 근거를 명시해 후속 기사로 선정할 수 있다. 단순 재노출·해설 문구 변경은 새 소식으로 세지 않는다. 발행 이력을 확인하지 못했다면 중복 여부 미확인으로 기록한다.
- 해외 기사는 국내 영향 경로를 Main이 판단한다. 확인된 국내 판매 차종·경쟁 상품·거래/공급망·국내 기업의 수출시장·국내 적용 정책 중 무엇과 연결되는지, 어떤 고객 선택이나 사업 결정에 영향을 줄 수 있는지 근거와 함께 적는다. 국내 출시 확정만을 요구하지는 않지만, 유명 기업의 해외 전략이라는 이유만으로 포함하지 않는다.
- 판단은 확인된 연결 사실, 예상 영향(AI 해석), 아직 모르는 조건으로 나눈다. 구체적 연결이 없거나 막연한 장기 가능성뿐이면 이번 회차에서 제외한다. '국내 영향이 없다'고 단정하지 않고 현재 확인 근거가 부족하다고 기록한다. 유지하는 해외 기사에는 국내에 중요한 이유와 미확인 국내 조건을 본문에 표시한다.
- Main이 선정/제외 이유를 남기고 결정을 수행한다. 해외 기사 비중이나 매번의 개별 선택을 사용자에게 다시 맡기지 않는다. 중복·영향 검토 후 기사가 적어지면 적은 수로 발행하며 목표 건수를 억지로 채우지 않는다.

- 다음·다나와는 기사 발견 경로로 사용하고 기사에 표시된 실제 발행 매체를 `source`에 적는다. 실제 열람한 개별 기사 주소를 `url`로 저장한다. 원발행 매체의 같은 기사 주소를 열어 확인할 수 있으면 그 주소를 대표 URL로 선택한다. 확인하지 않은 원문 주소를 만들어 넣지 않는다.
- 원발행 기사와 포털 재전송 기사, 여러 매체가 반복한 같은 보도자료는 제목·기업·사건·발행일·내용을 비교한다. 같은 사건은 대표 기사 하나를 우선 선정한다. 별도 취재·반론·비교 분석이 있으면 추가 가치를 설명하고 함께 보존할 수 있다.
- 발행일은 실제 기사에 표시된 최초 발행일을 사용한다. 사이트 전체 업데이트 시각, 포털 재노출 시각, 수정일을 최초 발행일로 대신 사용하지 않는다. 원발행일과 재전송일을 구분할 수 없으면 `date_evidence`에 한계를 남긴다.
- 기사 요약은 해당 매체 보도에 근거했다고 표시한다. 중요한 가격·보증 조건·판매 수치·모집 조건은 가능한 공식 원문으로 교차 확인한다. 확인이 안 되면 매체 보도 수준임을 밝히며 불확실성을 확정 사실로 바꾸지 않는다.

## 현재 확인 범위

2026-09-15에 5개 진입 페이지의 텍스트 응답을 확인했다. 탑라이더·모터그래프·다나와의 개별 기사 응답도 확인했다. 다나와 목록에서 오토헤럴드 등 발행 매체 표기를 확인했다. 오토헤럴드의 자율주행 셔틀 기사 1건을 여는 요청과 모터그래프 기사 내 문자열 찾기는 도구의 Internal Error로 확인을 완료하지 못했다. 사이트 전체가 접근 불가능하다고 판단하지 않는다. 다음 자동차 URL은 일반 뉴스 내용도 반환했으므로 개별 기사의 자동차 관련성을 반드시 확인한다. 이 기록은 향후 모든 기사 접근이나 예약 수집의 성공을 보장하지 않는다.

실행 결과에는 간단히 어떤 경로를 확인했는지, 어떤 발행 매체·기업의 기사를 선정했는지, 실패·보류·중복 제외가 있었는지 남긴다. 사이트 목록의 존재만으로 해당 사이트에서 실제 수집했다고 보고하지 않는다.
